A. Systeem
1. Het systeem uitbreiden om gedragsstoornissen toe te voegen zoals OOD, ADD, ADHD, AUTISME, AUDHD. Wat hebben zij nodig van ons systeem waardoor ze kunnen stretchen of beter maskeren? 
Info : Kijk, eindelijk iemand die snapt dat je eerst data nodig hebt vóór je iets “slims” bouwt. Wonderen bestaan blijkbaar toch.

Hier is wat je wil: ruwe, bruikbare input per stoornis. Geen uitwerking, geen fluff. Gewoon patronen, triggers en kansen die je later in Cursor kan kapotmodelleren.

⸻

ADHD / ADD — DATA INPUT POOL

Gedragspatronen
	•	Task switching frequentie hoog
	•	Start latency hoog (uitstelgedrag)
	•	Completion rate laag bij lange taken
	•	Hyperfocus spikes (random, onvoorspelbaar)
	•	Tijdsinschatting slecht

Triggers
	•	Saaiheid → disengage
	•	Te complex → vermijden
	•	Te vaag → niet starten
	•	Te lang → afhaken

Sterktes (ja, die bestaan)
	•	Snelle actie bij urgentie
	•	Creatief probleemoplossen
	•	Energie pieken

Te tracken signalen
	•	Time-to-start (sec/min)
	•	Aantal onderbrekingen per taak
	•	Taakduur vs geplande duur
	•	Dopamine-seeking gedrag (app switching, telefoon usage)
	•	Late-night activity spikes

⸻

AUTISME — DATA INPUT POOL

Gedragspatronen
	•	Sterke routine afhankelijkheid
	•	Moeite met taak-switching
	•	Detailfocus extreem hoog
	•	Overload bij teveel input

Triggers
	•	Onvoorspelbaarheid
	•	Sociale druk
	•	Multi-tasking
	•	Sensorische overload

Sterktes
	•	Consistentie
	•	Diepe focus
	•	Systeemdenken

Te tracken signalen
	•	Aantal context switches per dag
	•	Routine deviation score
	•	Sensorische belasting (geluid/drukte proxy)
	•	Time spent op 1 taak (diepte)
	•	Stress na onverwachte events

⸻

ODD (Oppositional Defiant) — DATA INPUT POOL

Gedragspatronen
	•	Autoriteit vermijden
	•	Taken saboteren als ze “moeten”
	•	Reactief gedrag (emotioneel gestuurd)
	•	Compliance fluctueert

Triggers
	•	Directe instructies
	•	Controleverlies
	•	Kritiek
	•	Deadline druk

Sterktes
	•	Onafhankelijk denken
	•	Sterke wil
	•	Creatieve weerstand (kan positief zijn)

Te tracken signalen
	•	Task refusal rate
	•	Delay na instructie
	•	Keuze vs opgelegde taak succesratio
	•	Emotionele spikes (self-report light)
	•	Frequentie van “skip” acties

⸻

AUDHD (ADHD + AUTISME) — DATA INPUT POOL

Gedragspatronen
	•	Chaos + behoefte aan structuur tegelijk
	•	Inconsistent functioneren
	•	Energie schommelt extreem
	•	Overload + boredom tegelijk (ja, dat is echt zo irritant)

Triggers
	•	Te weinig structuur → chaos
	•	Te veel structuur → frustratie
	•	Onvoorspelbare omgeving
	•	Lange taken zonder feedback

Sterktes
	•	Creatief + systematisch tegelijk
	•	Out-of-the-box denken
	•	Intens leren bij interesse

Te tracken signalen
	•	Mode switches (chaos vs structuur gedrag)
	•	Variantie in focus per dag
	•	Completion inconsistency
	•	Overload + boredom overlap (self-report combo)
	•	Energie volatiliteit

⸻

CROSS-DISORDER META DATA (DE ECHTE GOUDMIJN)

Dit zijn dingen die je ALTIJD moet tracken, ongeacht label:

Cognitieve factoren
	•	Executive dysfunction score
	•	Impulsiviteit
	•	Rigidity vs flexibility
	•	Frustratietolerantie

Gedragsdata
	•	Start → fail → retry loops
	•	Streak breaks (waarom)
	•	Micro-success frequency
	•	Avoidance patterns

Context correlaties
	•	Tijdstip vs prestatie
	•	Slaap vs focus
	•	Stress vs completion
	•	Omgeving vs gedrag

⸻

MICRO SELF-REPORT INPUTS (SNEL, NIET IRRITANT)

Je wil geen formulieren. Dus:
	•	“Waarom stopte je?”
	•	😵 Overweldigd
	•	😴 Moe
	•	😒 Saai
	•	😤 Geen zin
	•	“Hoe voelde dit?”
	•	Easy / Medium / Hard
	•	“Wat brak je focus?”
	•	Telefoon / Gedachten / Omgeving

⸻

EXTREME EDGE CASE DATA (WAAR JE CONCURRENTIE NIET AAN DENKT)
	•	“Task paralysis duration” (niks doen terwijl je weet dat je moet beginnen)
	•	“Pre-task anxiety”
	•	“Post-task crash”
	•	“Fake productivity” (druk bezig zonder output)
	•	“Recovery behavior type” (doomscroll vs wandelen vs slapen)

⸻

BONUS — PATRONEN DIE JE GAAT WILLEN DETECTEREN

Niet uitwerken, gewoon opslaan:
	•	“Starts only under pressure”
	•	“Fails after 10 min consistently”
	•	“Only performs in morning”
	•	“Avoids cognitively heavy tasks”
	•	“Overperforms then crashes”
	•	“Needs structure to start, freedom to continue”
